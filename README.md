# AvalancheView

Desktop-приложение на Python/PyQt6 для WRF, met_em и NetCDF. Центральная карта работает через **MapLibre GL JS + deck.gl + WebGL**, встроенные в QWebEngineView. Matplotlib используется для научных графиков и явно включаемого отладочного renderer.

Чтение данных, DatasetSeries, временная шкала, инспектор точки и восстанавливаемые панели сохранены. О миграции карты, научных допущениях и ограничениях: [docs/gis_renderer.md](docs/gis_renderer.md). Анализ реальной серии: [docs/dataset_series.md](docs/dataset_series.md).

CRYOWRF/SNOWPACK: активные элементы по SN_NLAYERS, NaN-маски карт/рядов, профиль по физической глубине с таблицей, доли, диагностические плотности и дискретные коды зерна. Реализация, проверки и приёмка на wrfout: [docs/cryowrf_snowpack.md](docs/cryowrf_snowpack.md).

## Запуск

```powershell
cd C:\LAVin\LAVinApp
. .\.venv\Scripts\Activate.ps1
py main.py
# Реальные файлы пользователя в проекте:
py main.py demo_data
# Синтетическая демонстрация:
py main.py --demo
```

Либо `./start.ps1`. На этой машине окружение использует Python 3.13.12. `main.py` умеет переходить в локальную `.venv`, если системный `py` выбирает старый Python. Для всех команд установки и проверки сначала активируйте окружение.

## Установка

Переносимый Windows exe и повторная сборка через PyInstaller: [docs/windows_exe.md](docs/windows_exe.md).

Windows 10/11, Python 3.11+, графический драйвер с WebGL 2. Проверено на Windows с Python 3.13.12, PyQt6/WebEngine 6.11 и Qt 6.11.2.

```powershell
py -m venv .venv
. .\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py -m pip install -r requirements-dev.txt
py main.py
```

`requirements-lock.txt` фиксирует установленное окружение. MapLibre 5.6.2, deck.gl 9.1.14 и Natural Earth уже включены в `avalanche_view/resources/web`; CDN при старте не нужен. Если нужен переносимый Python, используйте `tools/setup.ps1`. Cartopy и PyVista не требуются новой карте.

## Работа

1. **Файл → Открыть файл / серию файлов / папку модели**. Поддерживаются также перетаскивание файлов и папок, совместимые серии met_em/wrfout/NetCDF, вертикальные уровни, staggered-сетка и поворот ветра. Анализ и подготовка кадров выполняются в worker.
2. Двойной щелчок по переменной добавляет слой. **Слои** содержит группы MODEL, GIS, BASEMAP, TERRAIN. Модельные слои можно скрывать, удалять и менять местами стрелками или перетаскиванием внутри MODEL.
3. **Свойства слоя**: исходные ячейки, заливка, уровни, изолинии, заливка с изолиниями; диапазон, палитра, прозрачность, подписи, шаг и толщина линий. Сглаживание 3×3 включается явно и не меняет значения инспектора. Для сравнения времени задайте фиксированный диапазон.
4. Ветер: стрелки, метеорологические значки, линии тока, скорость со стрелками/значками. Выбирайте Wind Speed 10m, Wind Speed (UU/VV), Wind Speed (U/V) или компоненту совместимой пары. Автоматическая плотность оставляет исходные векторы, которые помещаются на экране.
5. Колесо мыши масштабирует карту; перетаскивание перемещает; правая кнопка/компас поворачивает и наклоняет. **Весь домен** вписывает фактическую границу сетки. **2D / 3D** меняют одну сцену; камера и слои сохраняются при смене времени. **К горам** наводит наклонённую камеру на высшую точку домена. 3D использует высоты DEM, а не значения температуры/снега как высоту.
6. **Карта → Подложка**: спутник NASA Blue Marble, спутник с подписями, топографическая, улицы, светлая, тёмная, рельеф, без подложки. **Настройки → Карты → Провайдеры** задаёт легальный XYZ/style URL, attribution, условия и API key. Ключи сохраняются в QSettings пользователя, вне исходников; это не зашифрованное хранилище.
7. **Карта → Рельеф и GIS**: по умолчанию выбран подробный мировой DEM Terrain Tiles; также доступны модельные HGT/HGT_M, локальный GeoTIFF DEM или настроенный raster-dem. Есть отмывка, освещение и усиление высот. Анализ: высота, крутизна, циклическая экспозиция, фильтр склонов 30–45°. Фильтр не является оценкой вероятности лавины.
8. **Карта → Добавить GIS-слой**: GeoJSON, Shapefile, GeoPackage и одноканальный численный GeoTIFF. Векторные геометрии переводятся из указанного CRS в WGS84. DEM и модельный рельеф остаются отдельными источниками.
9. Щелчок по карте выбирает ближайшую исходную ячейку. Инспектор показывает исходные значения, а **Временной ряд** открывает график в панели **Графики**. Высоты под курсором подписаны отдельно как «Модель», «DEM» и «Рельеф карты».
10. **Файл → Экспорт PNG** сохраняет GPU-сцену с заголовком, временем, легендами, масштабом и attribution с удвоенной плотностью пикселей. **Карта → Копировать карту** помещает PNG в буфер обмена. Экспорт включает ветер deck.gl.
11. **Вид → Панели** возвращает закрытые панели. Тема интерфейса независима от подложки. **Настройки → Язык / Language** переключает каталог русских/английских подписей; имена переменных и единицы не переводятся.

Без интернета работают встроенная обзорная география Natural Earth, «Без подложки», модельные поля, контуры, ветер, модельный и локальный DEM. Подробный мировой DEM, спутниковые и сетевые подложки требуют соединения; при ошибке мирового DEM приложение возвращается к модельному рельефу.

## Архитектура

```text
avalanche_view/data/          Dataset, WRFDataset, DatasetSeries, diagnostics
avalanche_view/gis/           capabilities, geometry, scientific preprocessing,
                             TerrainService, BasemapRegistry, local data service,
                             MapBridge and QWebEngineView host
avalanche_view/resources/web/ MapLibre/deck.gl scene and bundled dependencies
avalanche_view/ui/            Qt docks, timeline, layer properties, inspector
avalanche_view/visualization/ scientific plots and explicit LegacyMapRenderer
avalanche_view/services/      workers, file opening and legacy plot exports
```

Массивы Float64 и RGBA передаются бинарно через один управляемый HTTP-сервис на loopback со случайным портом и секретным путём. QWebChannel передаёт команды, метаданные и события. Гигантские JSON-массивы полей через bridge не проходят. Размер хранилища ограничен 192 MiB; DEM-кэш — 128 тайлов. Статичные данные дедуплицируются по содержимому. Сервис закрывается вместе с окном.

Классический NetCDF3 читается через netCDF4. На Windows для нелатинских путей используется короткое имя файла, если оно доступно; при отключённых именах 8.3 может потребоваться ASCII-путь. HDF5/NetCDF4 через h5netcdf читается по исходному Unicode-пути.

## Проверка

```powershell
. .\.venv\Scripts\Activate.ps1
py -m pytest -o cache_dir=verification/pytest-cache
py -m ruff check .
py -m pip check
py tools/verify_gis.py
```

`verify_gis.py` открывает реальный Qt WebEngine, проверяет met_em из `demo_data`, камеру, 3D DEM, ветер, экспорт, режимы и временные шаги. Снимки и отчёт сохраняются в `verification/gis/`. Тесту нужен доступ к локальным сокетам и дочерним процессам Chromium; ограниченная среда выполнения может их блокировать. Само приложение не отключает Chromium sandbox.

В netCDF4 1.7.4 при первом импорте из pytest возможно upstream-предупреждение Cython `numpy.ndarray size changed`; тесты чтения проходят, подавление предупреждения не добавлено.

## Диагностика и ограничения

Логи: `logs/avalanche_view.log`. При ошибке WebGL карта показывает диагностическое сообщение. Для явной проверки старой карты:

```powershell
py main.py --legacy-map --demo
```

Этот режим сохраняет прежние Matplotlib/Cartopy и необязательный PyVista. Автоматического переключения на него нет. `tools/preview_ui.py` и `tools/verify_series_ui.py` оставлены как проверки legacy.

Один активный модельный dataset/series. Общая сетка требует географических координат; домены через антимеридиан и широты вне Web Mercator пока отклоняются. Научные поля ограничены 250 000 ячеек на слой, без скрытого прореживания. Вертикальный профиль доступен для отмеченной ячейки и использует GHT/PRES, если координата присутствует; произвольный разрез вдоль линии пока отсутствует. Также пока отсутствуют объёмный рендер атмосферы, GUI экспорта анимации, MBTiles и лавинная модель. Дополнительные ограничения перечислены в [документации GIS](docs/gis_renderer.md).
